我从事 Web 与全栈开发约十四年，主干语言是 PHP（7.1 至 8.x），长期在生产环境使用 Laravel、ThinkPHP 等框架，配合 Linux（CentOS）+ 宝塔面板做部署与运维。做过会员营销、电商交易、报名缴费、医药电商（CRMEB）等多类业务系统，也参与过 IoT / uCPE 联调。

近年我在并行拓展技术边界：学习 Go、Python、Java(Spring)、Node.js(TypeScript)，并把 LLM / Agent 框架（Dify、LangChain、Coze、HiAgent、LangGraph）用于真实业务。同时也在评估从「PHP 后端」向「FDE（前线部署工程师）/ 全栈 / 业务管理」多条职业路径的发展。

这个站点是我对外的一个轻量门面：记录技术笔记、展示项目作品，也方便对接合作方。全站为静态页面、不含任何用户交互提交，依规完成公安联网备案。
