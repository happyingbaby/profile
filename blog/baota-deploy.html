宝塔面板部署静态站点的踩坑记录

2026-09 · 运维 / 部署

这个个人主站是纯静态页面，部署到已有的宝塔/CentOS 服务器上。下面是几个容易忽略、但直接影响访问与备案的点。

一、网站根目录要对

宝塔里每个站点有独立根目录（通常 /www/wwwroot/你的域名/）。把 index.html 等文件放到根目录，而不是上层，否则访问域名会拿到目录列表或 404。

二、ICP 备案与解析要一致

域名能访问的前提是 DNS 的 A 记录指向服务器公网 IP，且该 IP 的接入商与 ICP 备案一致。上线前先 ping 域名 确认解析到位，再去做公安备案填报（IP、接入商、域名商都要和这里一致）。

三、SSL 与强制 HTTPS

  • 宝塔「SSL」里一键申请 Let's Encrypt 免费证书。
  • 开启「强制 HTTPS」，避免用户用 http 访问出现备案号/内容不一致。
  • 证书到期前宝塔可自动续签，但建议留意通知。

四、备案号要挂且能点

ICP 备案号放在页脚，并链接到 工信部备案系统；公安备案通过后，把平台给的 HTML 代码（含图标）也放到页脚。两者都要真实可访问，审核人员会点。

五、上传方式

# 本地构建好后，用 scp 传整个目录到服务器根目录
scp -r ./个人主站/* user@服务器IP:/www/wwwroot/你的域名/

也可用宝塔文件管理器直接拖拽上传，适合小改动。改完清一下浏览器缓存再看效果。
